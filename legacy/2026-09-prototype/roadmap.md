## Phase 1 — AI 모델 고도화 (7월 중순 ~ 8월)

**목표**: 전체 AI 모델 목표 정확도 달성 + Pi5 실시간 추론 가능 수준으로 경량화

### 1-1. YOLOv8 행동 인식 개선
- [ ] 라벨링 기준 재정립 (휴식 vs 질병 의심 — 시간적 맥락 기준 추가)
- [ ] 연속 프레임 기반 시간 윈도우 데이터 증강 적용
- [ ] YOLOv8n → YOLOv8s 업그레이드 검토
- [ ] 2차 학습 및 검증 (목표: mAP-50 85% 이상)

### 1-2. CNN 감정 분류 개선
- [ ] 백본 교체: 경량 CNN → EfficientNet-B0
- [ ] 추가 데이터셋 확보 (Kaggle 외 소스 발굴)
- [ ] 전이 학습 재수행 (목표: 정확도 85% 이상)

### 1-3. librosa 짖음 패턴 분류 본격화
- [ ] 공개 음성 데이터셋 추가 확보
- [ ] MFCC + 멜스펙트로그램 파이프라인 고도화
- [ ] 경보 / 분리불안 / 놀이 3클래스 분류 모델 학습 (목표: 정확도 80% 이상)

### 1-4. Pi5 추론 최적화
- [ ] 학습된 모델 ONNX 변환
- [ ] INT8 양자화 적용
- [ ] Pi5 환경에서 추론 속도 측정 (목표: 15 FPS 이상)

**완료 기준**: 3개 모델 모두 목표 정확도 달성, Pi5에서 15FPS 실시간 추론 확인

## Phase 2 — 백엔드 서버 구축 (8월 ~ 9월 초)

**목표**: AI 분석 결과를 받아 저장·판단·제어하는 서버 완성

### 2-1. 프로젝트 구조 설계
- [ ] 디렉토리 구조 확정 (FastAPI 앱 레이아웃)
- [ ] SQLite DB 스키마 설계
  - `behavior_logs` (행동·감정·짖음 분석 결과)
  - `feeding_records` (급식 이력)
  - `sensor_data` (온습도·사료 잔량)
  - `care_actions` (케어 판단 이력)

### 2-2. FastAPI REST API 구현
- [ ] 분석 결과 수신 엔드포인트 (`POST /analysis`)
- [ ] 급식 제어 엔드포인트 (`POST /feeding/trigger`)
- [ ] 급식 스케줄 CRUD (`/feeding/schedule`)
- [ ] 센서 데이터 조회 (`GET /sensors/latest`)
- [ ] 케어 이력 조회 (`GET /care/history`)

### 2-3. MQTT 브로커 연동
- [ ] Mosquitto 브로커 설치 및 설정
- [ ] 토픽 구조 설계 (`petmind/sensor/#`, `petmind/control/#`, `petmind/status`)
- [ ] Pi5 ↔ 서버 실시간 메시지 연동 테스트

### 2-4. 케어 판단 엔진 구현
- [ ] 규칙 기반 판단 로직 작성
  - 분리불안 감지 → 진정 음악 재생
  - 배고픔 감지 → 급식량 자동 조정
  - 질병 의심 → 긴급 알림
- [ ] 알림 4단계 분류 로직 (정보 / 주의 / 경고 / 긴급)
- [ ] FCM(Firebase Cloud Messaging) 또는 WebSocket 알림 전송 구현

**완료 기준**: Postman으로 전체 API 정상 동작 확인, MQTT 메시지 송수신 확인

---

## Phase 3 — 하드웨어 통합 (9월)

**목표**: Pi5 + 센서 + AI 모듈 + 백엔드를 하나의 파이프라인으로 연결

### 3-1. AI 모듈 Pi5 이식 완료
- [ ] ONNX 모델 Pi5 배포
- [ ] 카메라 → YOLOv8/CNN 실시간 추론 파이프라인 구성
- [ ] 마이크 → librosa 실시간 분석 파이프라인 구성

### 3-2. 급식 제어 로직 완성
- [ ] 서보모터 PWM 제어 + 로드셀 피드백 루프 구현
  - 배출 → 무게 측정 → 목표량 도달 시 정지
- [ ] 배출량 오차 ±5g 이내 캘리브레이션 재검증

### 3-3. 환경 제어 시스템
- [ ] DHT22 데이터 주기적 수집 → MQTT 전송
- [ ] 온습도 임계값 초과 시 DC 쿨링팬 자동 가동 로직

### 3-4. Pi5 → 서버 데이터 파이프라인
- [ ] AI 분석 결과 → MQTT → FastAPI → SQLite 전체 흐름 검증
- [ ] 케어 판단 엔진 → 급식 제어 명령 → Pi5 서보모터 동작 확인

**완료 기준**: 카메라 영상 입력부터 급식 제어까지 자동 파이프라인 1회 완전 동작
