# 피드백 2 (피드백 2.m4a)

## 1. 현재 시스템 구조에 대한 확인 (교수 ↔ 학생)

- 카메라 영상에서 개의 상태(예: "불안해 보인다")를 텍스트로 만들어 LLM의 컨텍스트로 넣는 구조.
- 마이크로 짖는 소리를 인식해 "10초에 2번 짖었다" 같은 텍스트로 변환.
- 두 텍스트(영상 기반 + 소리 기반)를 클라우드 LLM에 전달 → LLM이 "배고픈 것 같다" 등 상태를 해석하고 사용자에게 알려주는 흐름. 학생이 이 구조가 맞다고 확인.

## 2. 핵심 지적 사항

### (1) LLM(VLM)으로 "동작"을 인식하기는 어렵다
- 스틸샷(이미지 한 장)으로는 "화난 표정" 같은 **표정/정적 상태**는 판단 가능.
- 하지만 "제자리에서 빙글빙글 돈다", "앉았다 일어났다" 같은 **동작**은 연속된 영상이 필요해서 단일 이미지 기반 모델로는 어려움.
- 학생 답변: 개 감정(표정) 관련 데이터셋은 5가지 정도 찾았으나, 동작 쪽은 아직 테스트하지 못함.

### (2) 동작 인식에는 시계열 모델이 필요
- LSTM(Long Short-Term Memory) 같은 시계열 모델을 사용해 연속 프레임에서 동작(돌고 있다, 앉았다 일어난다 등)을 분류하고, 그 결과를 텍스트로 만들어 LLM에 입력하는 방식을 제안.
- 마이크 소리를 텍스트로 바꾸는 것과 같은 방식으로, 동작 분류 결과를 LLM 컨텍스트에 넣어주면 된다는 설명.

### (3) 현재 선택한 모델의 적합성 의문
- 지금 고려 중인 모델은 특별한 모델이 아니라 개념 설명용에 가까워 보이며, 실제 용도에 쓰기에는 적합하지 않을 수 있다는 의견(?).
- 학생은 개 오브젝트를 찾아 동작을 파악하려는 계획이었으나, 오브젝트 탐색만으로는 부족하다는 취지의 지적.

### (4) 소리(짖음) 감지 파이프라인이 구체적이지 않음
- 마이크 입력은 결국 음성(wav) 파일이므로, 전처리 단계가 필요.
- 음성 파일에서 특징점을 추출해 "며칠 동안 몇 번 짖었는지", 빈도·음향 특성을 계산하는 과정이 있어야 하는데 현재 자료에는 "짖음 감지"라고만 적혀 있어 구체성이 없음.
- 학생: 짖음 감지는 일단 이용할 예정(사용할 도구는 인식 불명).
