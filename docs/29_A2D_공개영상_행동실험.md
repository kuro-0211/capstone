# 파트 29 — A2D 공개 영상으로 짧은 행동 인식 실험

작성일: 2026-10-11. 목표는 10초 궤적이 끊겨 `unknown`이 되는 실제 영상에 적용할 수 있는 **짧은 입력 후보**를 검증하는 것이다. 아직 기본 4종 행동 모델을 교체하지 않는다.

## 자료와 정답의 범위

[University of Michigan A2D 공식 페이지](https://web.eecs.umich.edu/~jjcorso/r/a2d/)의 본체·평가 아카이브를 받았다. 본체는 1,645,504,841바이트, SHA-256 `2abb6c6a35791ddb53ea3ee75b72a116d2595982a3bb22504442d4a52810f9c5`다. 공식 행동 인식 `AR.mat`에서 단일 행동만 붙은 개 영상을 골랐다. 선정 결과는 학습 쪽 먹기 72·달리기 57·걷기 19, 공식 테스트 쪽 먹기 18·달리기 15·걷기 8로 총 189편이다. 클립 원본과 모델은 `artifacts/`에만 보관하고 Git에 배포하지 않는다. 공식 [README](https://web.eecs.umich.edu/~jjcorso/r/a2d/files/README)의 과학 연구·비상업 이용 조건을 따른다.

이번 이진 실험의 양성은 **걷기 또는 달리기**, 음성은 **먹기**다. A2D의 `none`은 다른 행동도 포함하므로 정지로 바꾸지 않았다. 이 자료는 회전·왕복·정지의 시간별 정답을 제공하지 않으므로 기존 4종 LSTM의 전체 정확도 자료로 쓰지 않는다. 영상별 주행 카메라, 사람, 다른 개, 물체에 따른 혼동도 있다.

## 실제 처리와 평가

`scripts/prepare_a2d.py`가 공식 단일 라벨과 학습·테스트 분할을 읽고 개 영상을 추출한다. `scripts/prepare_a2d_trajectories.py`가 각 영상 가운데 3초에서 5fps, 15개 지점을 YOLOv8n으로 관찰한다. 한 마리만 탐지, 9/15개 이상 검출, 0.6초 이하 공백, 무리한 중심점 도약 없음 등의 품질 조건을 지킨 결과 **58편**이 남았다. 같은 개의 겹친 부분 박스를 보수적으로 제거하고 뚜렷한 우세 박스를 채택해 초기 42편, 첫 수정 48편보다 늘었다. 학습은 먹기 23·이동 13, 별도 검증은 먹기 6·이동 3, 공식 테스트는 먹기 9·이동 4였다. 131편 제외 사유는 복수 개 15, 검출 부족 97, 짧은 영상 6, 도약 8, 긴 공백 5편이다. 이 제외율 자체가 현재 탐지기의 적용 범위 한계다.

`scripts/train_a2d_short.py`는 3초 입력 LSTM을 학습하고 **학습·검증만으로** 체크포인트와 판단 임계값을 정했다. 공식 테스트 정답은 체크포인트나 임계값 계산에 넣지 않았다. 단, 첫 평가를 본 뒤 중복 박스 처리 코드를 개선하고 같은 테스트를 다시 사용했으므로 완전히 독립적인 최종 성능 평가가 아니라 **탐색적 평가**다. 검증에서 정밀도 80% 이상과 양성 2개 이상 조건을 만족하는 임계값이 없어서 안전한 거부 임계값 1.0을 선택했다. 따라서 공식 테스트 결과는 TP 0, FP 0, FN 4, TN 9, 이동 재현율 **0%**다. 임계값 0.5로 단순 판정하면 TP 4, FP 5, FN 0, TN 4, 이동 재현율 100%, 정밀도 44.4%다. 검증으로 선택한 중심점 이동거리 기준선은 공식 테스트에서 TP 4, FP 6, FN 0, TN 3, 이동 재현율 100%, 정밀도 40%다. 시험 표본이 13편이라 작은 차이로 성능을 일반화할 수 없다.

**결론:** 새 LSTM은 안전 임계값에서 양성을 하나도 찾지 못하고, 임계값 0.5에서도 단순 기준선을 확실히 앞서지 못했다. `artifacts/a2d_short/a2d_short_lstm.pt`는 연구용 후보로만 보관한다. 기본 `artifacts/lstm/trajectory_lstm.pt`와 실시간 영상 경로를 변경하지 않았다. 모델 학습을 했다는 사실과 실사용 정확도 향상을 구분한다. 자세한 결과와 파일별 예상·예측은 `artifacts/a2d_short/evaluation.json`, 데이터 선정 기록은 `artifacts/datasets/a2d/manifest.json` 및 `short_manifest.json`에 있다.

별도 미세조정 탐지기에 중복 제거를 결합하면 3초 품질 통과 영상이 87편까지 늘었지만 공식 테스트의 이동은 2편뿐이었다. 이 자료로 다시 학습한 3초 LSTM도 검증 임계값 1.0, 테스트 이동 0/2 감지여서 제품에 채택하지 않았다. 별도 결과는 `artifacts/datasets/a2d/candidate_short_manifest.json`과 `artifacts/a2d_short_detector_candidate/evaluation.json`에 있다. 데이터 수 증가와 행동 정확도 향상을 혼동하지 않는다.

## 다음 판단 기준

공식 개 박스 주석으로 탐지기 후보를 미세조정해 별도 평가했다. 이후 고정 카메라에서 직접 촬영한 3~10초 구간에 정지·이동·회전·왕복 시간별 정답을 붙여야 기본 4종 정확도와 `unknown` 비율을 같이 개선했다고 말할 수 있다.

공식 주석을 이용한 별도 탐지기 학습·평가는 [파트 30](30_A2D_공식주석_개탐지_평가.md)에 기록했다. A2D 자료는 다음 순서로 재현한다. 큰 원본 파일은 로컬 `artifacts/`에 저장하며 Git에는 넣지 않는다.

```powershell
.\.venv\Scripts\python.exe -m scripts.download_research_archive a2d
.\.venv\Scripts\python.exe -m scripts.download_research_archive a2d_eval
.\.venv\Scripts\python.exe -m scripts.prepare_a2d
.\.venv\Scripts\python.exe -m scripts.prepare_a2d_trajectories
.\.venv\Scripts\python.exe -m scripts.train_a2d_short
```
