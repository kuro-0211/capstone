# 파트 7 — 전체 시연·장애·이력 보존

검증일: 2026-10-11

## 완료한 검증

1. 실제 HTTP 서버에서 합성 입력 3종을 연속 실행했다. LSTM 모델이 있는 현재 환경에서 관찰 6건, 제안 3건, MCP 성공 3건, 가상 음악 2건 완료를 확인했다.
2. 공개 음원 `1-32318-A-0.wav`의 후보 9개와 공개 이미지 재생 영상의 LSTM 결과를 관찰로 저장했다. MCP 검색·제안·승인·가상 장치 완료까지 확인했다. 영상과 음원은 같은 시각에 녹화된 자료가 아닌 합성 시연 조합이다.
3. 가상 장치가 실패 응답을 보낸 명령이 `failed`로 저장되는 것을 실제 HTTP로 확인했다.
4. 장치 응답 없이 약 **30.20초**를 기다린 명령이 `timed_out`으로 저장되는 것을 확인했다. 이 검증에서는 DB 시각을 임의로 바꾸지 않았다.
5. 백엔드 프로세스를 종료하고 다시 실행한 뒤 공개 입력 시연의 관찰 4건·제안 1건·MCP 성공 1건·완료 액션 1건이 그대로 조회됐다.
6. Python 테스트 32개, Flutter 화면 테스트 2개, 정적 분석·웹 릴리스 빌드가 통과했다.

## 기록 파일

- `scripts/verify_flow.py`, `verify_media_flow.py`, `verify_faults.py`: 다시 실행할 수 있는 검증 명령.
- `docs/evidence/http_flow_summary.json`: 합성 3종 처리 결과.
- `docs/evidence/public_flow_summary.json`: 공개 입력 전체 연결 결과.
- `docs/evidence/fault_verification.json`: 실패·실제 시간초과 결과.
- `docs/evidence/persistence_verification.json`: 서버 재시작 전후 값 비교.
- `README.md`: 실행·데이터 준비·테스트·주의할 검증 범위.
- `requirements-lock.txt`: 이번 Windows 환경의 설치된 패키지 버전. `pip check` 결과 의존성 충돌 없음.

## 미완료·현재 한계

- Gemini는 실제 키 설정을 기다리고 있다. 현재 이 검증의 제안은 규칙 제공자다.
- 실제 브라우저 자동화 연결이 없어 브라우저 클릭·시연 영상은 아직 확보하지 못했다. Flutter 위젯 흐름과 웹 빌드, 실제 HTTP는 각각 검증했다.
- 실제 Pi·물리 음악 재생·카메라/마이크 스트림·실제 반려견 정확도·케어 효과는 검증 전이다.
- 추가 후보 중 타임라인과 간단한 처리 평가 수치는 구현했다. 프로필·보호자 피드백·케어 전후 비교·평소 패턴 비교는 후속 항목이다. 평소 패턴은 실제 장기 기록이 필요하다.
