# AI 생성 음성을 이용한 임시 시연

더 자연스러운 Gemini TTS와 **사례별 실제 UI 업로드·RAG 녹화**는 후속 [기록](43_자연스러운_음성_사례별_UI_RAG_시연.md)을 참조한다. 이 문서는 최초 Windows TTS 시연의 기록이다.

이 시연의 목적은 **실제 음원 입력 → 음성 LSTM 후보 확인 → 시연 담당자 의견 → 외출 요약 → 과거 기록 근거 확인**이라는 제품 흐름을 보여주는 것이다. 실제 가정에서의 감지 정확도나 새 독립 평가 결과를 뜻하지 않는다.

## 자료와 출처

- 사람 말소리: Windows TTS로 생성한 「문 닫고 갈게. 잠깐만 기다려. 금방 돌아올게.」
- 개 짖음 소리: [FSD50K 공개 원본](https://zenodo.org/records/4060432) ID `15791`, 업로더 `laurent`, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). 이 원본은 이전에 살펴본 평가 자료이므로 새 독립 성능 근거로 쓰지 않았다.
- 두 소리를 첫 5초에 음량 비율을 달리하여 섞었다. 세 번째 대조 음원에는 TTS 말소리만 넣었다. **실제 집에서 녹음한 자료가 아니다.** 원본과 결과 파일의 해시는 Git 제외 `artifacts/ai_sound_demo_20261012/manifest.json`, `ui_seed_results.json`에 있다.

| 5초 시연 음원 | 실험 후보 LSTM 점수 | 기준 0.900 | 해석 |
|---|---:|---|---|
| 짖음 + 생성 말소리 | 0.920 | 후보 감지 | 성공 사례 |
| 짖음 + 더 큰 생성 말소리 | 0.788 | 후보 미감지 | 놓침 사례 |
| 생성 말소리만 | 0.140 | 후보 미감지 | 비짖음 대조 사례 |

세 점수는 별도 시연 DB에 파일을 실제 업로드했을 때 받은 API 응답이다. 영상의 음원 카드는 이 **세 파일의 실제 소리**를 재생한다. 음원 단위 점수이며 짖음 시작·종료 시각의 정확한 검출 결과가 아니다. 보호자 확인으로 표시한 내용은 실제 보호자가 아닌 **시연 담당자의 의견**이다.

## 영상에서 볼 수 있는 동작

최종 영상은 Git 제외 `artifacts/ai_sound_demo_20261012/PetMind_AI_sound_presentation_demo.mp4`다. 앞부분에 세 음원과 점수·놓침을 나란히 보여주고, 뒷부분에서 실제 Edge 브라우저의 Flutter UI를 연속 조작한다. 브라우저 파일 선택 자동화가 안정적이지 않아 음원 업로드·의견 등록은 **녹화 전에 별도 DB에 API로 미리 등록**했다. 브라우저에서는 등록된 사건 검토, 귀가·외출 종료, RAG 근거 요약, 케어 제안 평가를 조작했다. 이 점을 영상에도 명시했다.

시연 서버는 실험 후보 `household_bark_candidate.pt`를 환경 변수로 선택했다. 기본 운영 체크포인트는 교체하지 않았다. 요약 수치는 코드가 저장 기록에서 계산하며, 설명은 **로컬 기록 검색과 규칙 기반 제공자**로 만들었다. 이 영상에서 Gemini API의 실제 문장 생성은 사용하지 않았다. 출처와 보호자 의견을 검색 근거로 구분하는 흐름을 시연한다.

영상 검증: 1280×720, 54.34초, H.264 영상과 AAC 음성. 전체 파일을 FFmpeg로 디코딩했고, 사례 화면·귀가 화면 프레임을 확인했으며 사례 1 구간의 음성이 무음이 아닌 것을 측정했다. 영상 카드·웹 화면에 공개·합성 시연이라는 표시가 나온다.

## 남은 검증과 결정

혼합 학습 후보는 이전 [사전검증](41_생활소음_혼합_짖음_시연_사전검증.md)에서 FSD 생활 소음 동시 표기 짖음 1/6만 찾았고 ESC 평가 오탐은 3/392에서 9/392로 늘었다. 이번 세 사례는 그 결정을 뒤집는 정확도 근거가 아니다. 후보를 기본 모델로 승격하지 않는다. 다음에는 실제 가정 녹음의 짖음 위치를 사람이 확인하고, 개체·원본별로 분리한 새로운 평가 자료에서 놓침과 오탐을 함께 측정해야 한다.

## 재현에 필요한 파일

음원 생성: `scripts/synthesize_walkthrough.ps1`, `scripts/prepare_ai_sound_demo.py`.
시연 DB 등록: `scripts/seed_ai_sound_demo.py`.
브라우저 녹화: `scripts/record_ai_sound_review.cjs`.
영상 합성: `scripts/build_ai_sound_demo_video.py`.
원본 WAV·체크포인트·DB·완성 MP4는 Git에 넣지 않는다.

회귀 검증: 전체 Python 테스트 **140개**, Flutter 테스트 **21개** 통과; `flutter analyze` 문제 없음; Flutter 웹 빌드 성공.
