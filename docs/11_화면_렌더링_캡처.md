# 파트 11 — 발표용 화면 렌더링 캡처

작성일: 2026-10-11

실제 HTTP 서버의 공개 입력 시연 결과, 최신 제안·완료 액션·타임라인·처리 수치를 읽어 `artifacts/ui_snapshot.json`으로 저장했다. Flutter 테스트 렌더러에 이 응답과 실제 공개 영상 미리보기·좌표·음성 파형을 공급해 `artifacts/flutter_dashboard.png`를 생성했다.

```powershell
cd petmind_app
flutter test tool\capture_dashboard.dart --update-goldens
```

이 도구는 화면 산출물을 만드는 도구이며 브라우저 통합 테스트가 아니다. 네트워크 응답은 저장된 실제 API 결과를 사용하고, 영상 미리보기는 실제 추적 산출물을 사용한다. 한글과 아이콘 폰트를 로컬에서 로딩해 전체 화면 구성과 글자·출처·상태를 시각적으로 확인했다.

브라우저 자동화 도구에 연결된 브라우저가 없어 실제 Chrome 클릭·동영상 녹화는 아직 미완료다. 이 캡처를 실제 브라우저에서 클릭한 증거로 설명하지 않는다. HTTP 전체 처리 검증과 Flutter 기능 테스트, 렌더링 캡처를 각각 구분한다.

[공개용 캡처](evidence/flutter_dashboard_render.png)는 이 저장소에 포함했다. 원본 입력·JSON snapshot은 로컬 산출물로 보관하며, 다시 생성하려면 입력 준비·실제 HTTP 시연·응답 snapshot 저장이 먼저 필요하다.
