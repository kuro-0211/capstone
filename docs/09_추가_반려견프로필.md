# 파트 9 — 반려견 프로필·보호자 메모

검증일: 2026-10-11

## 완료 내용

- 반려견 ID별 이름·나이·생활 패턴·메모 저장/수정/조회 API와 SQLite 테이블.
- Flutter 프로필 편집 폼과 나이·이름 입력 검증.
- 케어 평가에 해당 반려견의 프로필만 추가. 다른 반려견 프로필은 포함하지 않는다.
- `guardian_input` 출처를 표시하며, Gemini 프롬프트에서 측정 결과와 구분하도록 한다.
- 기존 DB를 다시 만들지 않고 별도 `pet_profiles` 테이블을 추가했다.

수정: `database.py`, `routers/pets.py`, `services/profiles.py`, `services/care.py`, `providers.py`, Flutter `main.dart`, `tests/test_profile.py`.

## 검증

프로필 저장·수정·입력 검증·다른 반려견 혼입 방지·평가에 반영하는 테스트 2개를 추가했다. 전체 Python 테스트는 이후 추가 기능을 포함해 38개 통과했다. Flutter 분석·화면 테스트도 통과했다.

실제 HTTP의 `scripts/verify_extras.py`에서 가상 시연견 프로필을 저장하고 평가의 참고 정보로 조회되는 것을 확인했다. 검증 프로필 이름과 메모에는 실제 반려견 자료가 아님을 표시했다.

## 한계

프로필은 보호자 제공 정보다. 프로필만으로 상태나 질환을 판정하지 않는다. Gemini 실제 호출 검증은 API 키 설정 이후이며, 현재 테스트는 규칙 제공자의 근거 전달과 DB·API 연결을 검증했다.
