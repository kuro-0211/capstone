# 파트 4 — Flutter 전체 흐름 연결

검증일: 2026-10-11

## 완료 내용

기존 `petmind_app/lib/main.dart`의 대시보드·제안·승인·이력 화면을 이식하고 확장했다. 신규 프레임워크는 도입하지 않았다.

- 반려견 A/B 선택, 합성 과거 기록 준비, 3개 시나리오 분석·저장·평가.
- 질문 입력과 현재 관찰 ID 기반 재평가.
- 영상 궤적과 짖음 후보·dBFS, 처리 건수 표시.
- 같은 반려견 검색 기록·출처·인용 ID·MCP 도구 결과·표본 수 표시.
- 승인/거절 및 가상 장치 실행 이력, 전체 처리 타임라인.
- 관찰이 없으면 '데이터 없음'과 비활성 평가 버튼. 급식 UI 제거.
- API timeout을 검색·생성 처리 시간에 맞춰 조정. 선택 반려견이 바뀌면 이전 요청 결과를 적용하지 않는다.

## 검증 결과

`flutter pub get` 성공. `flutter analyze`: **No issues found**. `flutter test`: **2 passed**. `flutter build web --release`: 성공.

화면 테스트는 HTTP mock으로 관찰 ID 전달, 근거 표시, 승인 요청, 데이터 없는 초기 상태를 검증한다. 실제 HTTP 백엔드는 별도 파트 2에서 검증했다. 브라우저 UI 자동화 도구에는 연결된 브라우저가 없어 실제 브라우저 클릭·화면 캡처는 아직 미검증이다.

## 실행

백엔드와 가상 장치 에이전트를 켠 뒤 `petmind_app`에서 `flutter run -d chrome --web-port 8020`으로 실행한다. 현재 생성한 웹 빌드는 로컬 HTTP 서버 `http://127.0.0.1:8020`에서 제공한다. API 기본 주소는 `http://localhost:8010`이다.
