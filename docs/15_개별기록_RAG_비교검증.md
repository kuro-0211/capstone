# 파트 15 — 개별 기록 RAG와 구간 길이 보정

검증일: 2026-10-11

## 확인한 문제와 수정

공개 입력은 5초, 과거 시드 관찰은 30초이므로 원시 횟수만 비교하면 빈도를 반대로 설명할 수 있다. `services/frequency.py`에서 현재 후보 횟수를 분당 빈도로 환산하고, SQL로 계산한 과거 저장 구간의 빈도와 비교한다. 계산 결과는 검색 근거에 저장하고 Flutter에도 표시한다.

Gemini에는 구간 길이가 다르면 횟수를 직접 비교하지 않고 서버 계산의 분당 값만 사용하도록 명시했다. 저장 구간 비교를 실제 평소 패턴이나 이상 진단으로 표현하지 않도록 한다. 검색 실패, 기록 없음, 실제 과거 0회 값을 구분한다.

## 실제 개별화 검증

`scripts/verify_personalization.py`에서 두 가상 반려견에 **동일한 현재 관찰·동일한 질문**을 제공하고 과거 이력만 다르게 저장했다. 실제 MCP 도구와 Gemini를 호출했다.

| 항목 | 조용한 과거 이력 | 빈번한 과거 이력 |
|---|---:|---:|
| 현재 후보 빈도 | 4회/분 | 4회/분 |
| 과거 저장 구간 빈도 | 0회/분 | 16회/분 |
| 계산된 차이 | +4회/분 | -12회/분 |
| 실제 Gemini 설명 | 증가했다고 설명 | 12회/분 감소했다고 설명 |
| 인용한 기록 ID | 41, 42 | 44, 45 |

현재 입력·질문이 같고, 검색된 반려견 ID와 인용 집합이 섞이지 않으며, 실제 답변이 달라지는 것을 확인했다. 원본 결과: `docs/evidence/personalization_verification.json`.

## 테스트·화면

- 5초 2개 후보와 30초 8개 후보를 비교할 때 현재 24회/분 > 과거 16회/분으로 계산하는 회귀 사례.
- 과거 기록 없음·도구 실패·과거 실제 0회 값을 구분하는 사례.
- 전체 Python 테스트 **43 passed**, Flutter 기능 테스트 2개·분석·웹 릴리스 빌드 통과.

## 한계와 다음 검증

이는 합성 이력 두 사례를 통한 실제 RAG 연결·개별화 사례 검증이다. 자연어 검색 품질의 종합 벤치마크나 실제 반려견 기준선 평가가 아니다. 인용 ID 검증만으로 모든 자연어 설명의 사실 정확도가 보장되지는 않는다. 실제 브라우저 시연·영상·Pi·장기 실제 관찰·행동 정확도는 여전히 미검증이다.
