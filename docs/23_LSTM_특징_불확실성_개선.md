# 파트 23 — LSTM 특징·불확실성·공개 데이터 사전학습

작성일: 2026-10-11. 기존 LSTM과 API 구조를 유지했다.

## 수정 파일과 이유

| 파일 | 변경 |
|---|---|
| `pet_monitor/lstm.py` | 기존 위치·속도 4개에 속력·가속도 2개·방향 전환을 추가해 8개 특징 사용. v1 모델 호환 유지 |
| `scripts/train_lstm.py` | 실제 공개 모션의 다음 1초 예측 사전학습 → 기존 합성 4종 행동 분류. 촬영 그룹·파일 무결성 검사, gradient clipping, 분리 평가 |
| `pet_monitor/video.py` | 영상 결과에 특징 버전·학습 출처 추가, 새 체크포인트 실행 |
| `petmind/backend/main.py`, `schemas.py`, `services/observations.py`, `routers/media.py` | 관찰·케어 문맥에 LSTM 버전과 학습 출처 전달 |
| `tests/test_lstm_quality.py` | 특징 불변성, 균등 확률 unknown, 좌표 급변, BVH 손상 검사 |
| `petmind_app/lib/main.dart` | 특징 버전 및 실제 행동 정확도 미검증 표시 |

50샘플·5Hz·약 10초, 최소 80% 실제 추적 및 최대 0.65초 간격 규칙은 유지했다. 낮은 확신도(<0.75), 상위 두 클래스 차이(<0.25), 샘플 간 정규화 좌표 이동 >0.15이면 unknown 처리한다. 임계값은 현재의 보수적 초기 설정이며 실제 OOD 자료로 보정한 값이 아니다. 높은 softmax도 낯선 입력에서 틀릴 수 있다.

## 실제 실행 결과

원본 데이터와 분할은 [파트 22](22_공개_모션데이터_검증.md)를 참고한다. 행동 라벨을 임의 생성하지 않았다.

| 공개 모션 다음 1초 예측 | LSTM MSE | 단순 속도 유지 MSE | 판단 |
|---|---:|---:|---|
| validation 12구간 | 0.000653742 | 0.000811070 | 약 19.4% 낮음 |
| test 13구간 | 0.000346938 | 0.000316487 | 약 9.6% 높음 |

검증 결과로 체크포인트를 선택한 뒤 테스트를 실행했다. 개발 중 초기 1샘플 예측을 탐색한 뒤 다음 1초 예측 방식으로 바꾸었으며, 이 과정에서 같은 촬영 분할을 재사용했다. 따라서 최종 테스트 수치를 처음 보는 독립 블라인드 성적으로 취급하지 않는다. **실제 모션의 테스트에서 단순 기준보다 좋아졌다는 증거는 없다.** 공개 데이터는 실제로 사전학습에 사용했지만, 성능 향상 자체는 미확인이다.

합성 행동 분류: train 1,600 / validation 400 / test 400, 기존 시드 11/22/33 유지. validation·test argmax 정확도 100%, test 400개 모두 unknown 기준을 통과했다. 이는 제한된 합성 생성기의 성적이며 실제 개 영상 정확도가 아니다. 기존 v1도 이 합성 테스트에서 100%였으므로 분류 정확도 상승으로 발표하지 않는다.

v1은 `artifacts/lstm/trajectory_lstm_v1_backup.pt`에 보존했다. v2는 `artifacts/lstm/trajectory_lstm.pt`에 설치했다. 사전학습 전용 가중치는 `artifacts/lstm_v2/mocap_forecaster.pt`, 평가 전체는 [평가 JSON](evidence/lstm_v2_evaluation.json)에 저장했다.

DAVIS 재생 영상 재실행: 12초 / 추적 56샘플 / unknown 9.8초 / moving 2.2초. 이전 spinning 출력과 달라졌지만 행동 정답이 없으므로 개선 판정하지 않는다. 새 추적 영상은 `artifacts/video/tracked.mp4`다. 원본 시간 및 카메라 이동 한계는 유지한다.

최종 전체 Python 테스트 **52 passed**. 저확신·좌표 급변·손상 입력 검사와 기존 시나리오/API/MCP/장치 기능을 함께 확인했다. Flutter 테스트 2개, analyze, 웹 release 빌드도 통과했다.

## 남은 문제와 다음 작업

실제 행동 라벨, 개체 독립 평가, 고정 카메라 입력, 불확실성 보정이 필요하다. 앉기·눕기·잠·불안 등의 라벨을 중심 좌표만으로 확정하지 않는다. 사전학습 전후를 실제 카메라 정답 세트에서 비교한 뒤 모델 채택을 결정한다. 현재 v2의 근거는 특징 확장과 거부 처리·출처 추적이며 실제 행동 정확도 향상은 아니다.
