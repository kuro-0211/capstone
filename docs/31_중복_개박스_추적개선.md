# 파트 31 — 중복 개 박스 제거와 기본 추적 개선

작성일: 2026-10-11. A2D 공식 주석 분석에서 탐지기가 **같은 개의 큰 박스와 작은 부분 박스**를 동시에 내보내는 사례를 찾았다. 기존 추적 코드는 이를 여러 마리로 간주해 선택을 보류하거나 관찰 시퀀스를 끊었다.

`pet_monitor/detection.py`에 신뢰도 순으로 박스를 검사하고, 작은 박스의 80% 이상이 큰 박스와 겹치며 IoU도 0.2 이상인 경우에만 뒤 박스를 중복으로 제거하는 함수를 추가했다. 공간적으로 떨어진 두 마리는 유지한다. 이 함수를 기본 `pet_monitor/video.py`의 후보 선택과 A2D 3초 궤적 추출에 적용했다. YOLO 체크포인트·10초 LSTM·행동 라벨은 바꾸지 않았다. `tests/test_a2d_detector.py`가 부분 중복은 제거하고 떨어진 개는 유지하는 조건을 확인한다.

| 평가 입력 | 중복 제거 전 | 제거 후 | 아직 남은 한계 |
|---|---:|---:|---|
| A2D 3초 품질 통과 영상, 기존 YOLO | 48/189편 | **58/189편** | 131편 제외 |
| A2D 3초 품질 통과 영상, A2D YOLO 후보 | 50/189편 | **87/189편** | 테스트 이동 구간 2편 |
| InterPet dog08 기본 모델 선택 프레임 | 81/123 | **85/123** | 행동 전부 `unknown` |
| InterPet dog08 최장 구간 | 3.61초 | **7.63초** | 10초 LSTM 입력 미달 |
| InterPet dog10 기본 모델 선택 프레임 | 85/133 | **90/133** | 행동 전부 `unknown` |
| InterPet dog10 최장 구간 | 6.94초 | **7.34초** | 10초 LSTM 입력 미달 |
| TigDog 첫 15초 기본 추적 관찰 | 149개 | **216개** | 신원·정답 시간별 확인 없음 |
| TigDog 첫 15초 기본 `moving` 출력 | 0.20초 | **1.00초** | 실제 정확도 향상이라고 단정 불가 |

A2D 탐지기 후보는 중복 제거 후 공식 주석 박스를 더 많이 찾았지만, 별도 InterPet의 최장 구간이 기본 탐지기보다 짧고 TigDog 행동 출력은 전부 `unknown`이었다. 후보는 미채택하고 기본 YOLOv8n에만 중복 제거를 적용했다. `artifacts/a2d_detector/external/`에 처리 전·후 JSON과 영상이 있다. 움직임 출력 증가와 추적 구간 증가는 **coverage 지표**이며 4종 행동 정확도가 아니다. 실제 두 마리의 부분 가림 상황과 고정 카메라의 시간별 정답 영상으로 추가 확인이 필요하다.

전체 Python 테스트 **66 passed**와 `pip check`를 확인했다. 별도 데이터 후보의 성능·반복 테스트 사용 제한은 [파트 29](29_A2D_공개영상_행동실험.md), [파트 30](30_A2D_공식주석_개탐지_평가.md)에 기록했다.
