# 파트 26 — 필요한 행동 데이터가 웹에 있는가

확인일: 2026-10-11. 사용자의 질문에 따라 실제 배포 파일과 라벨 형태를 추가 확인했다. 이번 작업은 데이터 선정 조사이며 추가 모델 학습·정확도 향상 보고가 아니다.

## 확인된 후보

| 자료 | 확인된 내용 | 현재 프로젝트 적용 조건 |
|---|---|---|
| [InterPet4D 공식 배포](https://huggingface.co/datasets/ohicarip/interpet4d) | 13마리, 실제 공개 ego 영상 227개, 자세·모션 자료, 클립 설명 및 검토 메타데이터. 접근 제한 false, CC BY-NC 4.0 | 영상·자세 학습 후보. 클립 설명은 행동별 시작/종료 시각의 정답이 아님. 현재 4종 분류의 시간 구간 라벨을 추가하거나 실제 제공 라벨에 맞춘 과제를 정의해야 함 |
| [Movement Sensor Dataset](https://pmc.ncbi.nlm.nih.gov/articles/PMC8777071/) | 45마리의 걷기·뛰기·앉기·서기·눕기 등, 영상 검토로 붙인 센서 정답 | 공개 학습 입력은 IMU. 현재 영상 중심 좌표 LSTM에 직접 넣을 수 없음. 센서 입력 추가 시 별도 후보 |

| [실내 행동·circling 영상 연구](https://www.frontiersin.org/journals/toxicology/articles/10.3389/ftox.2026.1758963/full) | 실내 다중 개 추적·먹기·마시기·circling 등의 라벨을 사용한 연구 | 데이터는 J&J 소유로 공개 즉시 다운로드 불가. 저자 요청 및 소유자 허가 필요. 연락하거나 신청하지 않음 |

## 실제 배포 확인

InterPet4D 연구자 페이지의 Dataset 링크에서 Hugging Face 공식 저장소를 확인했다. API에서 접근 제한이 없고 `video/.../sync_ego_cam.mp4`가 227개임을 확인했다. 논문의 다중 시점 수집 설명과 별개로, 현재 확인한 공개 MP4 목록은 ego 영상이다. 공개 고정 카메라 영상도 있다고 단정하지 않는다.

클립 설명 JSON은 228개이며 접근·앉기 등 여러 행동이 한 클립 안에 설명된다. 설명에는 행동 문장별 타임스탬프가 없다. 자세 데이터나 설명을 검증된 4종 행동 정답으로 바꾸지 않는다. 전체 영상을 이번에 다운로드하거나 학습하지 않았다.

Spin Alert는 Figshare API와 약 5MB ZIP 파일 목록을 확인했다. pickle 역직렬화는 하지 않았다. 연구에서 동기화 영상을 촬영했다는 사실과 실제 공개 파일에 영상이 들어 있다는 주장은 구분한다.

## 판단과 다음 방향

웹에 실제 개 행동 데이터는 존재한다. 현재의 **정지·이동·회전·왕복 네 종류, 원본 영상, 프레임/시간 정답, 공개 이용**을 동시에 만족하는 바로 적용 가능한 자료는 이번 조사에서도 확인하지 못했다.

현재 영상 시스템에는 InterPet4D를 우선 후보로 검토할 만하다. 일부 영상의 해상도·원본 FPS·카메라 움직임·자세 품질과 실제 행동 구간을 확인하고, 제공 정보로 지원되는 과제부터 정한다. 앉기/눕기/잠 등은 중심 좌표로 구분할 수 없으므로 자세 특징이 필요하다. 영상·반려견 단위의 분리 평가를 유지한다.

회전·왕복은 공개 영상의 적합 구간에 독립 정답을 추가하는 방법이 현실적인 대안이다. 다운로드량이나 학습량 증가만으로 정확도가 향상된다고 가정하지 않는다.

참고: [InterPet4D 연구자 페이지](https://interactive-intelligence-lab.github.io/InterPet4D-Homepage/), [Spin Alert 연구 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC12607429/). 이전 실제 평가 결과는 [파트 25](25_실제데이터_성능비교.md)에 유지한다.
