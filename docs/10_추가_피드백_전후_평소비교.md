# 파트 10 — 피드백·케어 전후·평소 패턴 비교

검증일: 2026-10-11

## 완료 내용

- `guardian_feedback` 테이블, `routers/feedback.py`: 짖음 여부·제안 적절성·검토 메모 저장과 반려견별 조회. 원래 관찰과 제안이 일치해야 한다.
- 과거 검색 근거에 해당 기록의 최신 보호자 의견 최대 2건을 포함한다. 현재 평가 시각 이후에 작성된 의견은 제외한다.
- `routers/comparisons.py`: 완료 명령 전후 같은 반려견·출처·길이의 관찰 구간 비교. 후속 관찰이 없으면 자료 부족으로 표시한다.
- 평소 패턴은 최근 14일 같은 한국 시간대의 `live` 관찰만 사용하며 최소 10개 구간과 3일 이상의 기록을 요구한다. 합성·공개 입력으로 실제 기준선을 만들지 않는다.
- Flutter 피드백 폼, 실행별 전후 조회, 평소 패턴 조회와 자료 부족 상태.
- 별도 테이블 추가 방식이라 기존 관찰·제안·명령 이력은 유지된다.

## 실제 검증

`scripts/verify_extras.py`를 실제 HTTP 서버에서 실행했다.

1. 가상 시연견 프로필을 저장하고 평가 근거에 반영했다.
2. `synthetic_demo`로 명시한 검증용 의견을 저장했다. 실제 보호자 평가로 표현하지 않는다.
3. 가상 음악 완료 후 **31초를 기다린 뒤** 합성 휴식 관찰을 생성했다.
4. 같은 30초 구간의 후보 횟수 전후 비교가 `ok`로 반환됐다. 응답의 `causality_established=false`와 `demo_windows`를 확인했다.
5. 평소 패턴은 실제 기록이 없으므로 `insufficient_data`가 반환됐다.

근거: `artifacts/extras_verification.json` 및 `docs/evidence/extras_verification.json`.

## 테스트

원래 관찰과 제안 연결, 다른 반려견 피드백 격리, 과거 의견 검색, 완료 전/후 자료 부족, 같은 길이의 전후 구간, 합성 기준선 거부, 실제 기록의 표본·기간 조건을 테스트했다. 전체 **38 passed**. 충분한 실제 관찰을 가정한 기준선 계산은 격리된 테스트 DB의 가상 fixture로 검증했으며 실제 반려견 표본을 확보한 것은 아니다.

## 남은 실제 검증

피드백을 자동 학습 정답으로 쓰지 않는다. 후보 횟수의 감소를 음악의 효과로 해석하지 않는다. 실제 보호자 의견과 실제 동일 시간대의 장기 관찰은 앞으로 수집해야 한다. 평소 비교 결과는 빈도 차이이며 정상/이상 판정이 아니다.
