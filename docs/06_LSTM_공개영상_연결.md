# 파트 6 — 초기 LSTM 학습·공개 입력 추적

검증일: 2026-10-11

## 완료한 개발

- `pet_monitor/lstm.py`: 중심 좌표·속도 4차원 입력, 단일 LSTM 층(48 hidden)과 분류기. 정지·이동·회전 궤적·왕복 궤적 4종.
- `scripts/train_lstm.py`: 기존 시뮬레이터의 궤적에 회전·크기·속도·잡음을 다양화. 시퀀스 단위로 분리한 학습·검증·테스트 생성과 모델 저장.
- `pet_monitor/video.py`: 공개 YOLOv8n·ByteTrack으로 첫 선택 개의 ID를 유지하고 정규화 좌표를 LSTM에 입력. ID를 다른 개로 바꾸지 않는다.
- `scripts/prepare_davis.py`: 공식 DAVIS 이미지 입력·출처 문서 보관·재생용 영상 구성.
- `scripts/evaluate_video.py`: 추적 좌표·프레임별 추론·불확실성·영상 미리보기·표시 영상 저장.
- 백엔드 합성 시나리오도 저장된 LSTM 모델이 있으면 실제 모델을 사용한다. 없으면 기존 규칙 분석을 사용하며 응답에 모델을 표시한다.
- Flutter에는 합성 학습 여부, 공개 음원 파형, 공개 영상 추적 궤적·출처를 연결했다.

## 공개 입력에서 확인한 사실

Wikimedia 영상은 원본/공식 변환본 요청이 429 등으로 실패했다. 이후 계획에 포함된 DAVIS 공식 다운로드를 사용했다.

DAVIS는 JPEG 이미지 시퀀스이며 원본 녹화 FPS를 확보하지 못했다. `dog` 60개 프레임을 **5fps의 12초 시연 재생 영상**과 25fps의 짧은 재생 영상으로 따로 구성했다. 이는 원본 녹화 시간이나 실제 움직임 속도 측정이 아니다. 변환 조건은 입력 manifest와 화면의 주석에 표시한다.

- 5fps dog 재생 입력에서 선택 추적 ID 1, **56개 추적 샘플**을 확보했다.
- 첫 9.8초는 관찰 부족 등으로 unknown, 이후 **2.2초에서 모델 추론 출력**을 확보했다.
- 해당 구간의 예측은 spinning이었다. 카메라 이동·합성 학습의 영향이 있어 실제 반려견의 회전 행동으로 판정하지 않는다.
- dog-gooses, dogs-scale 입력도 확인했으나 선택 ID 추적 샘플이 각각 37, 13개로 부족해 unknown이었다. 이를 성공한 행동 분류로 계산하지 않는다.
- 현재 기본 시연 보고서는 `artifacts/video_analysis.json`의 dog 입력이다.

## 추적 누락 처리

처음에는 탐지 한 프레임만 빠져도 시퀀스를 초기화해 모든 공개 구간이 unknown이었다. 같은 ID가 유지된 짧은 누락은 시간축 보간으로 처리하도록 보완했다. 5Hz 기준 최대 두 번의 누락(간격 0.65초 이내), 실제 관찰 80% 이상, 약 10초 시간 범위가 확보되어야 한다. 긴 단절·ID 미탐지·부족한 구간은 unknown이다. 보간 수와 기준을 결과에 기록한다.

체크포인트 재로딩, 클래스별 합성 입력, 짧은 누락 보간, 긴 단절·관찰 부족을 검증했다. 분석·API·MCP 포함 **32 passed**.

## 남은 검증

실제 동작 라벨·원본 시간축·고정 카메라 입력을 확보해야 행동 정확도를 평가할 수 있다. 앉았다 일어남은 초기 LSTM 클래스에 포함하지 않았다. 공개 영상과 별도 음원을 결합한 입력은 실제 동시 녹화가 아닌 합성 시연으로 표시한다.
