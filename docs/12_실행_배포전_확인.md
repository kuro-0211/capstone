실제 Chrome 클릭·녹화는 연결된 브라우저 도구가 없어 미검증이다. 캡처는 테스트 렌더러 산출물이며 실제 브라우저 동작의 증거를 대신하지 않는다. Pi·물리 음악·원본 카메라 시간축·실제 행동 정확도·장기 기록·케어 효과도 미검증이다.

전체 목표는 위 미완료 항목이 남아 있어 완료로 처리하지 않았다. 검증한 소프트웨어 흐름과 실제 환경의 검증 범위를 구분한다. 로컬 변경만 저장했으며 GitHub push나 외부 배포는 수행하지 않았다.
