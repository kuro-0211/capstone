# 파트 22 — 공식 공개 데이터 확보와 오염 방지

작성일: 2026-10-11. 사용자 요청: 부족한 LSTM 데이터를 웹의 검증된 자료로 보완한다.

## 실제로 확보한 데이터

SIGGRAPH 2018 / ACM Transactions on Graphics 논문 **Mode-Adaptive Neural Networks for Quadruped Motion Control**의 AI4Animation 개 모션 캡처 원본을 연구자 공식 배포 링크에서 다운로드했다. 논문 저자는 He Zhang, Sebastian Starke, Taku Komura, Jun Saito이며 원본 모션 제공자는 Bandai-Namco Studios다.

- [연구자 저장소·이용 조건](https://github.com/sebastianstarke/AI4Animation)
- [논문 및 원본 데이터 안내](https://github.com/sebastianstarke/AI4Animation/blob/master/AI4Animation/SIGGRAPH_2018/ReadMe.md)
- [공식 다운로드](https://starke-consult.de/AI4Animation/SIGGRAPH_2018/MotionCapture.zip)
- 라이선스: CC BY-NC 4.0. 연구·교육 목적 사용, 상업 사용 제외. 원본과 모델은 로컬 artifacts에 두며 GitHub에 업로드하지 않았다.
- 참고한 저장소 commit: `98aff6c87d73e4af0cbf50df2586f58532475662`.
- 다운로드 파일 33,422,409 bytes, SHA-256 `0ecd909b673cfca5e20c3f568376dcf27d7da3bd153957c2b034d95af366132a`.

해시는 이번 다운로드의 로컬 무결성·버전 고정 값이다. 배포자가 발표한 체크섬을 대조한 것은 아니다. 공식 출처 및 연구 문헌이 있다는 사실이 모든 라벨·샘플의 무오류를 보장하지 않는다.

## 사용 방식과 검사

`scripts/prepare_mocap.py`를 추가했다. BVH 프레임 수·채널 순서·FPS·유한값을 검사하고 루트 X/Z 좌표를 원래 시간축에서 5Hz로 샘플링한다. 프레임 시간을 늘려 데이터 수를 부풀리지 않았다. 파일 SHA-256과 시작점 이동을 제거한 루트 궤적 해시로 중복을 검사했다. 이번 자료에서 중복 제외 건수는 0이다. 모든 유사 영상·유사 동작을 탐지하는 검사는 아니다.

51개 파일, 30개 촬영 묶음을 시드 2026으로 분할했다. `D1_047`, `D1_047z`, 같은 촬영의 KAN 하위 클립은 같은 분할에 둔다. 10초 구간끼리는 겹치지 않는다. 분할 간 촬영 묶음 중복은 학습 시에도 검사한다. 전처리 NPZ 해시가 manifest와 다르면 학습을 거부한다.

| 분할 | 10초 구간 수 | 용도 |
|---|---:|---|
| train | 195 | 다음 1초의 이동 예측 사전학습 |
| validation | 12 | 사전학습 체크포인트 선택 |
| test | 13 | 선택 후 별도 평가 |

**전부 한 마리의 캡처 자료다. 반려견이 다른 독립 평가가 아니다.** 사람 판정의 정지·이동·회전·왕복 라벨도 없다. 임의로 행동 정답을 생성하지 않고, 라벨 없이 실제 움직임을 배우는 사전학습에만 사용했다. 월드 좌표를 2D로 투영하므로 카메라 박스 중심과도 분포가 다르다.

## 검토했지만 사용하지 않은 자료

후속 갱신: 아래 TigDog 다운로드 실패는 당시 기록이다. 이후 [파트 25](25_실제데이터_성능비교.md)에서 공식 자료 다운로드에 성공해 실제 영상 평가에 사용했다. 기존 모션 사전학습에 사용한 것으로 소급하지 않는다.

- [TigDog 공식 자료](https://calvin-vision.net/datasets/tigdog/): 프레임별 행동 라벨이 있으나 실제 다운로드 요청은 HTTP 406으로 실패했다. 공식 README의 걷기·달리기·머리 돌리기는 현재 4종 궤적 라벨과 같지 않다. 확보하거나 학습했다고 기록하지 않는다.
- [Animal Kingdom](https://sutdcv.github.io/Animal-Kingdom/Animal_Kingdom/action_recognition/README_action_recognition.html): 연구 자료지만 다운로드 신청 절차가 있다. 신청·개인정보 제출은 하지 않았다.
- 기존 DAVIS: 추적 실행용으로 유지한다. 원본 FPS 및 현재 행동의 정답이 없으므로 행동 정확도 평가용으로 사용하지 않는다.

## 실행·증거·다음 작업

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.prepare_mocap
.\.venv\Scripts\python.exe -X utf8 -m scripts.train_lstm --pretrain-data artifacts/datasets/ai4animation/windows.npz --output artifacts/lstm_v2
```

검사 결과와 파일별 출처·FPS·해시·촬영 그룹·분할: [manifest](evidence/ai4animation_manifest.json). 파싱 오류·NaN·동일 촬영 명칭에 대한 회귀 테스트를 추가했다.

다음으로 고정 카메라 원본 영상에서 사람이 확인한 4종 궤적 라벨을 확보해야 한다. 같은 반려견·촬영·중복 구간을 분리하고, 공개 모션 사전학습이 실제 카메라 행동 분류에 도움이 되는지 별도로 평가한다.
