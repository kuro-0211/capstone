# RAG 검증과 개선 — 2026-10-12

## 검증 범위

현재 로컬 저장소의 FastAPI·SQLite·MCP·Gemini API 키로 평가했다. 원본 사용자 기록을 변경하지 않도록 별도 SQLite DB에 5초 음원 2건과 **실험용 가상 보호자 의견**을 만들었다. 첫 외출에는 `external_or_tv`, 다음 외출에는 `pet_vocalization` 의견을 남겼다. 이 시나리오는 출처·인용 연결 검사이며 실제 반려견 상황에서의 정확도 평가는 아니다.

| 측정 | 결과 | 해석 |
|---|---:|---|
| 과거 순서 필터, 개발자가 만든 20문항 | 필수 근거 8/20 | 기존 기준 |
| 현재 의도별 선택, 같은 20문항 | 필수 근거 20/20 | 작은 작성 문항 회귀 검사 |
| 별도 작성 20개 관찰·질문 쌍, 키워드 검색 | Recall@5 0.35, MRR 0.254 | 다른 표현의 질문을 자주 놓침 |
| 동일 쌍, 실제 Gemini 임베딩 검색 | Recall@5 1.00, MRR 0.747 | 이 작은 평가 집합에서 개선; 실제 사용자 성능 아님 |
| 실제 Gemini·MCP·SQLite 격리 연동 | 외출 질문 3건 근거 적합, 범위 밖 질문 1건 무근거, 케어 질문 1건 과거 리뷰 인용 | 단일 시나리오 기능 확인 |
| 전체 Python 회귀 | 134개 통과 | 기존 경로 호환 확인 |

출력 원본은 로컬 `artifacts/rag/`의 `evaluation_lexical.json`, `evaluation_semantic.json`, `holdout_after.json`, `current_live_result.json`에 있다. API 키·개인 데이터는 이 문서나 Git에 저장하지 않았다. 실행 명령은 `python -m scripts.evaluate_rag`, `python -m scripts.evaluate_rag --semantic`, `python -m scripts.evaluate_rag_current`다.

## 발견하고 수정한 문제

1. **TV 확인 질문이 최신 반려견 소리 의견을 잘못 인용했다.** 외출 RAG가 현재 세션의 최신 의견만 우선했고 `external_or_tv` 라벨을 질문과 대조하지 않았다. 질문이 과거 확인을 요구할 때 같은 반려견·같은 입력 방식의 이전 외출 최대 5개에서 의견을 조회하고, TV 질문은 TV/외부 소리 라벨과 일치하는 의견만 후보로 둔다. 수정 후 이전 관찰 #1만 인용했다.
2. **케어 RAG에서 음원 확인 의견이 빠졌다.** 일반 피드백 테이블만 검색하고 음원에 저장된 의견을 읽지 않았다. 이제 같은 관찰의 음원 리뷰를 검색 문맥에 포함하고, 시연 담당자와 보호자 출처 및 의견 작성 시각을 구분한다. 다른 반려견과 질문 시각 이후 의견은 제외한다. 수정 후 실제 MCP·임베딩·Gemini 경로에서 이전 관찰 #1의 `external_or_tv`를 읽고 인용했다.
3. **Gemini가 필수 근거를 일부 선택하지 않아 설명 전체가 대체 방식으로 바뀌었다.** 적법한 근거 ID를 선택한 경우, 서버가 이미 검색한 정식 사실에서 빠진 요약·비교·품질 근거를 보충하고 `selection_completed=true`를 표시한다. 알 수 없는 ID 등 잘못된 선택은 기존처럼 대체 처리한다. 수정 후 관련 외출 질문 3건 모두 Gemini 경로로 답했고, 수치는 서버가 계산한 사실을 그대로 사용했다.

## 남은 개선 우선순위

1. **독립 사용자 평가:** 실제 보호자의 질문·정답 근거와 원본 음원을 확보해 인용 적합성, 잘못된 확정 표현, 검색 실패율을 별도로 측정한다. 현재 20문항 성적을 실제 정확도로 발표하지 않는다.
2. **케어 문장 사실 검증:** 케어 제안 경로는 인용 ID의 범위만 검사한다. Gemini가 생성한 문장·숫자 자체가 원본 수치와 일치하는지 자동 대조하는 검사가 필요하다. 현재 외출 요약 경로는 서버가 문장을 렌더링하므로 범위가 다르다.
3. **검색 범위와 속도:** 과거 외출 의견은 최근 5개 세션만 확인하며, 의미 검색은 최대 100개 후보를 임베딩한다. 장기간 데이터에서 응답 시간·누락률·비용을 측정한 후 범위와 캐시를 조정한다.
4. **출처 구분 유지:** 공개 시연 자료, 실험용 가상 의견, 실제 보호자 의견은 서로 다른 출처다. 실제 사용 검증 전까지 시연 결과를 보호자 케어 효과로 해석하지 않는다.

운영 기본 경로는 로컬 단일 사용자 시제품이며 인증과 외부 공개는 아직 완료되지 않았다.
