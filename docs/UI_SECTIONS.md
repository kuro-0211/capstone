# 화면 분리 작업 기록 — 2026-10-12

기존 긴 대시보드를 상단 메뉴 5개로 나눴다. 기존 테마와 API를 유지했다.

| 메뉴 | 구성 |
|---|---|
| 홈 | 최근 관찰·처리 실적·음성 신호, 실시간 카메라, 주요 기능 바로가기 |
| 외출·음원 | 외출 시작/종료, 사용자 음원 입력·보호자 확인, 하루·귀가 요약, 사건 영상 근거 |
| RAG·케어 | 질문 작성, 현재 관찰 평가, 케어 제안·검색 근거·비교 |
| 기록 | 처리 타임라인, 승인·실행 이력 |
| 설정·시연 | 반려견 선택·프로필, 기존 합성 시연·공개 입력 도구 |

`petmind_app/lib/main.dart`: 메뉴와 독립 스크롤 영역 추가. IndexedStack으로 질문·외출 화면 상태를 유지하며 홈에서 나가면 카메라 뷰를 제거해 미리보기 요청을 중단한다. 홈의 기존 영상 궤적 카드는 최근 관찰 카드로 변경했다. 저장된 기록 수치이며 실시간 카메라 행동 분석 결과가 아니다.

`petmind_app/test/widget_test.dart`: 기존 시나리오·승인·빈 데이터·좁은 화면 테스트에 메뉴 이동을 반영했다. 홈에서 다른 파트가 숨겨지는지, 질문 유지, 카메라 화면 종료, 기록 메뉴 이동을 추가 검증했다.

Flutter 테스트 21개 통과. 정적 분석 오류 없음. 실제 Pi 영상 검증은 사용자 요청에 따라 이후 장비 연결 시 진행한다. 브라우저 자동 제어 연결이 없는 환경이라 이번 화면 구성은 위젯 테스트와 웹 빌드로 확인했다.
