# 파트 5 — 공개 WAV 분석·평가

검증일: 2026-10-11

## 완료 내용

- `pet_monitor/audio.py`: WAV 읽기, 스테레오→모노, 16kHz 리샘플링, 음성 이벤트·RMS 파형 요약.
- `pet_monitor/bark.py`: 파일 마지막 후보를 처리 시각을 늘리지 않고 한 번만 종료하는 `finish()` 추가.
- `scripts/prepare_media.py`: 고정 공개 음원 20개 다운로드, SHA-256·출처·카테고리·라이선스 기록.
- `scripts/evaluate_audio.py`: 짖음 음원과 대조 음원의 후보 존재 여부를 비교.
- `routers/media.py`: 준비된 공개 입력만 선택·분석·관찰 저장. Flutter 파형·출처 화면 연결.

## 실제 평가 결과

ESC-50에서 정렬된 목록의 dog/rain/sea_waves/clock_tick 각 5개, 총 20개의 5초 음원을 사용했다. 모델 파라미터를 이 목록에 맞춰 조정하지 않았다.

| 클립 수준 판정 | 건수 |
|---|---:|
| 개 소리 클립에서 후보 감지 | 5 |
| 개 소리 클립에서 후보 미감지 | 0 |
| 비개 소리 클립에서 후보 오탐 | 3 |
| 비개 소리 클립에서 후보 없음 | 12 |

이 평가는 **고정 20개 클립의 후보 존재 여부**이며 개별 짖음 횟수의 정답 라벨은 없다. 따라서 짖음 정확도 85% 또는 완성된 분류기로 발표하지 않는다. 에너지 감지는 소리의 발생원을 구분하지 못하며 대조 음원 15개 중 3개의 오탐이 실제로 확인됐다.

원본: `artifacts/audio_evaluation.json`, `artifacts/media/manifest.json`, 개별 저작자 표기 `artifacts/media/ESC50_LICENSE.txt`.

## 테스트

파일 끝 후보 중복 방지·시각 유지, 스테레오 입력, 리샘플링, 빈 음원 오류 처리를 추가했다. 분석·백엔드·MCP·모델 재로딩 포함 **32 passed**.
