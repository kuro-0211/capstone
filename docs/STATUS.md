# PetMind 현재 상태와 작업 기록

기준일: 2026-10-11. 구현 사실과 계획을 구분한다. 목표 전체 완료를 선언한 문서가 아니다.

**발표용 영상:** [파트 39](39_Genesis_브라우저_설명영상.md)에 Genesis UI 전후 비교·공개 Dog 감지/놓침·RAG 근거·한계를 설명하는 2분 57초 편집 영상과, 새 시연 DB에서 외출 시작→음원→의견→귀가→원본을 이어서 조작한 30.6초 무음 브라우저 녹화를 구분해 기록했다. 두 파일 모두 Git 제외 `artifacts/`에 있다.

**새 환경 재현 확인:** Git 파일만 있는 별도 작업 폴더에서 공개 음원 4개를 새로 받아 해시를 검증했고, 설명 영상을 재생성해 디코딩했다(당시 `f594f8c`). 후속 `54a00ff`도 별도 Git 폴더에서 Python 114개 통과·모델 산출물 의존 1개 건너뜀, Flutter 18개 통과·분석·웹 빌드를 확인했다. 체크포인트 없이도 WAV 입력→5초 귀가 요약→근거 설명이 작동하며 `/health`와 화면은 모델 미준비를 명시한다. 상세 조건은 [파트 38](38_자체피드백_안정성_출처_사용성.md)에 기록했다.

**자체 피드백 보완:** [파트 38](38_자체피드백_안정성_출처_사용성.md)에 자동 새로고침 경합·요청량, 일부 API 실패 시 기록 조회, 원본 유실 표시, 공개 시연/사용자 음원 출처 분리, 사용자 화면 표기를 수정한 이유와 검증을 기록했다. 별도 시연 DB의 실제 브라우저에서 공개 ESC-50 음원 업로드→시연 의견→근거 재생→귀가 설명을 확인했다. 시간 질문의 근거 검색·답변 범위, 감지·놓침 사례 4개를 준비하는 명령, 별도 DB의 두 번째 외출 재현 스크립트, HTML 오류 안내와 사용자 음원 기본 모드·정확한 모드 전환 안내, 보조 API 장애 때 핵심 관찰 유지, 과거 인용 기록의 원본 근거 열기와 모바일 선택 항목 축약도 보완했다. 최신 전체 회귀는 Python 115개·Flutter 18개 통과, Flutter 정적 분석·웹 빌드 완료다.

**화면 디자인 적용:** 사용자 제공 Genesis 스타일을 Flutter 공통 테마와 외출·음원·근거 흐름에 적용했다. 기존 다크 UI와 새 화면의 비교 이미지, 390px 모바일 화면, 글꼴·캡처 조건은 [파트 37](37_Genesis_UI_적용_비교.md)에 기록했다. 이번 변경에서 Flutter 분석·5개 테스트·웹 빌드가 통과했다. Python 전체 회귀에서 FSD 테스트의 누락 인자를 보완해 106개 테스트가 통과했다.

**최신 공개 음원 개발·시연:** [파트 36](36_발표전_공개음원_검증과_시연.md)에 ESC-50/FSD50K 공식 분할, 세 조건 오디오 LSTM 비교, 음원 5초 구간 화면, 공개 자료와 보호자 의견 분리, 별도 DB의 외출·귀가·MCP 질문 검증을 기록했다. 검증 평균 F1이 0.663→0.746으로 올랐어도 기존 FSD 평가 F1은 0.436→0.430으로 낮아져 운영 체크포인트를 유지했다. Python 106개·Flutter 4개 테스트, 정적 분석·웹 빌드 통과. 로컬 설명 영상은 3분 51초이며 실제 API 응답의 Flutter 재렌더 화면으로 만든 것으로, 브라우저 클릭 녹화와 구분한다. 아래 항목은 개발 당시의 이력 수치다.

## 최신 방향과 검증 (음성 중심)

최신 변경은 [33 — 음성 중심 개발 진행](33_음성중심_개발진행.md)을 우선한다. 아래 이전 영상 실험 기록은 보존하되, 주 분석은 공개 음원 기반 오디오 LSTM 실험과 보호자 확인 기록으로 이동했다. 웹캠은 근거 장면 확인용이며 급식기·추가 센서는 제외한다.

- 외출 세션, 음원 저장/학습 동의 분리, 확인 추천, 보호자 의견, 철회/만료 삭제 및 독립 검수 후 학습 목록 내보내기를 구현했다. 실제 사용자 개인화 성능은 미검증이다.
- 공개 음원으로 브라우저 외출 시작 → 업로드 → 보호자 의견 → 귀가 요약/MCP 근거 → 오디오 재생을 확인했다. 이후 실제 브라우저 캡처와 편집 설명 영상, 별도 30.6초 연속 자동 조작 녹화를 확보했다([파트 39](39_Genesis_브라우저_설명영상.md)). 외부 사용자 검증은 남았다.
- FSD50K 평가 120개에서 기존 오디오 LSTM 재현율 28.3%, F1 43.6%다. CLAP 비교 F1 83.5%는 사전학습 중복을 배제하지 못하며 실제 가정 정확도가 아니다. 운영 모델은 자동 교체하지 않았다.
- FSD 공식 학습 음원 240개를 추가한 실험에서 LSTM 검증 성능이 나아지지 않아 기존 모델을 유지했다. 복합 질문·최근 보호자 의견 검색과 하루 근거 설명을 구현했다. 개발자 작성 고정 질문의 근거 포함 성공은 8/16→16/16이나 독립 사용자 정확도는 아니다.
- 당시 전체 Python 99개, Flutter 4개 테스트 및 정적 분석·웹 빌드가 통과했다. 브라우저에서 하루 설명과 영상 외출 시작→관찰→귀가→MCP 요약→근거 영상 7~12초 재생을 검증했다. iframe 클릭 겹침에 대응하는 새 탭 플레이어를 추가했다. 최신 회귀 수치는 위 자체 피드백 보완 항목을 따른다.
- 후속 실제 Gemini 검증: 가상 기록 3건에서 허용 근거·수치·인용 보존을 확인했다. 구현에 쓰지 않은 별도 개발자 질문 20개는 이전 8/20→개선 15/20이었다. 표현 다양성 실패 5건이 남았고 외부 사용자 정확도는 미검증이다. 최신 증거와 한계는 파트 33을 따른다.

## 최신 LSTM·RAG 개선

[파트 27 — InterPet4D 적용·평가](27_InterPet4D_적용_평가.md): 공개 자세 파일 225개를 사용해 후보 모델을 실제 학습했다. 반려견 분리 89/14/21 구간. 좌표 예측 MSE는 기존 v2보다 12.84% 감소했지만, 영상 이동 재현율은 44.4%→0%로 악화해 후보를 기본 모델로 채택하지 않았다.
[파트 28 — 추적 ID 재연결 개선](28_추적_ID_재연결_개선.md): 짧은 ID 변경에 외형·위치·크기 기반 보수적 연결을 적용하고 ByteTrack을 약 15fps로 갱신했다. 같은 보류견 영상 2편에서 선택 프레임 29→81/85로 증가했지만 연속 구간이 3.61/6.94초라 LSTM coverage는 여전히 0%다. 실제 분류 정확도 개선은 입증되지 않았다.
[파트 29 — A2D 3초 행동 후보](29_A2D_공개영상_행동실험.md): 공식 단일 개 행동 영상 189편을 확보했다. 3초 유효 궤적 58편으로 LSTM을 학습했으나 검증 기반 임계값에서 공식 테스트 이동 4편을 모두 놓쳐 미채택했다.
[파트 30 — A2D 개 탐지기 후보](30_A2D_공식주석_개탐지_평가.md): 공식 주석 585프레임으로 탐지기를 미세조정했다. 중복 제거 후 동일 A2D 테스트에서 주석 개 박스 재현율 61.8%→82.4%, 정밀도 94.4%→87.5%였다. 외부 행동 출력은 개선되지 않아 기본 탐지기·LSTM을 유지했다. 같은 테스트를 탐색 과정에 반복 사용했으므로 최종 독립 정확도 주장이 아니다.
[파트 31 — 중복 개 박스 제거](31_중복_개박스_추적개선.md): 같은 개의 큰·작은 박스를 여러 개로 잘못 처리하지 않게 했다. 기본 탐지기의 InterPet 최장 구간은 dog08 3.61→7.63초, dog10 6.94→7.34초. TigDog `moving` 출력은 0.20→1.00초였으나 4종 정확도 개선은 아직 증명되지 않았다.

- [파트 22 — 공식 공개 데이터](22_공개_모션데이터_검증.md): 실제 개 모션 파일 51개, 촬영 그룹 30개, 195/12/13 구간 분리. 출처·이용 조건·해시·시간축 확인. 임의 행동 라벨 없이 사전학습에 사용.
- [파트 23 — LSTM v2](23_LSTM_특징_불확실성_개선.md): 8개 특징, 저확신·좌표 급변 unknown, v1 호환·백업, 공개 모션 사전학습과 합성 행동 분류. 모션 테스트 오차는 단순 기준보다 9.6% 높아 실제 성능 향상은 미확인.
- [파트 24 — RAG v2](24_RAG_기간_의미검색_개선.md): 한국 시간 기간, 보호자 메모·케어 근거, 실제 Gemini 의미 검색·캐시·명시적 폴백. 자체 20질문 Recall@5 25%→100%, Top-1 60%. 독립 실제 사용자 평가가 아님.
- 실제 embedding→공식 MCP→Gemini→인용 통합 검증 성공, 특징 v2가 API에 연결됨. 로컬 의미 검색 활성화. 백엔드 8010, 웹 8020.

추가 계획 6개 중 타임라인·평가 수치·프로필·피드백·전후 비교 인터페이스를 구현했다. 평소 패턴은 계산 및 표본 기준을 구현했지만 실제 장기 기록이 없어 적용 검증은 미완료다.

## 핵심 검증 한계

[파트 25 — 실제 공개 데이터 성능 비교](25_실제데이터_성능비교.md): TigDog 사람 판정과 원본 영상 시각을 확인해 평가했다. 최종 적격 이동 구간 9개에서 v1/v2 재현율 모두 44.4%, unknown 5개였다. 실제 성능 향상은 확인되지 않았다. 비이동·회전·왕복의 독립 정답이 부족해 전체 4종 정확도는 미평가다. 실제 좌표 예측의 고정 모델 비교도 v2 오차가 약 0.98% 더 컸다. 다음 우선순위는 추적 실패와 카메라 이동 영향 개선, 실내 조건의 독립 정답 데이터 확보다.

- LSTM 100%는 합성 테스트 400개 성적이다. 실제 반려견 행동 정확도는 아니다.
- 음성은 에너지 기반 후보다. 공개 비개 소리 15개 중 3개에서 오탐이 확인됐다.
- DAVIS는 JPEG 시퀀스다. 재생용 5fps 시간축과 원본 녹화 시간을 구분한다. 카메라 이동 미보정, 다른 음원과의 결합은 합성 시연이다.
- 가상 음악 완료는 물리 음악 재생이 아니다. 전후 관찰 변화는 음악의 인과 효과가 아니다.
- 실제 로컬 브라우저의 외출·공개 음원·검토·귀가 근거 흐름과 서버 장애·복구는 파트 38에서 확인했다. 화면 녹화 파일은 아직 없다. Pi SSH 가상 명령 왕복은 파트 20에서 확인했다. 카메라·실시간 마이크·물리 음악 재생은 미검증이다.

## 다음 작업

실제 로컬 브라우저 연속 시연은 [파트 38](38_자체피드백_안정성_출처_사용성.md)에서 확인했다. 녹화 파일 확보와 새 환경 재설치는 남았다. [파트 17](17_브라우저_연결준비.md)의 연결 오류는 이전 실행 세션 기록이다.

1. 실제 Gemini·MCP·인용은 검증했다. 키는 로컬 `.env`에만 유지하며 발표에서는 실제 제공자와 인용 근거를 표시한다.
2. 화면 캡처와 웹 빌드, 실제 브라우저 흐름·연결 복구는 확인했다. 다음으로 화면 녹화 파일과 새 환경 설치·복구 절차를 검증한다.
3. Pi 가상 명령 왕복은 검증됐다. 실제 카메라·마이크·음악 재생과 연결 복구를 다음 단계로 검증한다.
4. A2D에서는 탐지 후보의 박스 재현율이 올랐지만 두 InterPet 원본의 분류 coverage는 0%다. 고정 카메라/영상 안정화와 ID 연속성, 4종의 시간별 정답 확보가 다음 기술 작업이다. 이후 실제 라벨·장기 관찰·보호자 의견으로 정확도와 케어 효과를 평가한다.
