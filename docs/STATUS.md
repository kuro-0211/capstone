## 최신 LSTM·RAG 개선

[파트 27 — InterPet4D 적용·평가](27_InterPet4D_적용_평가.md): 공개 자세 파일 225개를 사용해 후보 모델을 실제 학습했다. 반려견 분리 89/14/21 구간. 좌표 예측 MSE는 기존 v2보다 12.84% 감소했지만, 영상 이동 재현율은 44.4%→0%로 악화해 후보를 기본 모델로 채택하지 않았다.
[파트 28 — 추적 ID 재연결 개선](28_추적_ID_재연결_개선.md): 짧은 ID 변경에 외형·위치·크기 기반 보수적 연결을 적용하고 ByteTrack을 약 15fps로 갱신했다. 같은 보류견 영상 2편에서 선택 프레임 29→81/85로 증가했지만 연속 구간이 3.61/6.94초라 LSTM coverage는 여전히 0%다. 실제 분류 정확도 개선은 입증되지 않았다.
[파트 29 — A2D 3초 행동 후보](29_A2D_공개영상_행동실험.md): 공식 단일 개 행동 영상 189편을 확보했다. 3초 유효 궤적 58편으로 LSTM을 학습했으나 검증 기반 임계값에서 공식 테스트 이동 4편을 모두 놓쳐 미채택했다.
[파트 30 — A2D 개 탐지기 후보](30_A2D_공식주석_개탐지_평가.md): 공식 주석 585프레임으로 탐지기를 미세조정했다. 중복 제거 후 동일 A2D 테스트에서 주석 개 박스 재현율 61.8%→82.4%, 정밀도 94.4%→87.5%였다. 외부 행동 출력은 개선되지 않아 기본 탐지기·LSTM을 유지했다. 같은 테스트를 탐색 과정에 반복 사용했으므로 최종 독립 정확도 주장이 아니다.
[파트 31 — 중복 개 박스 제거](31_중복_개박스_추적개선.md): 같은 개의 큰·작은 박스를 여러 개로 잘못 처리하지 않게 했다. 기본 탐지기의 InterPet 최장 구간은 dog08 3.61→7.63초, dog10 6.94→7.34초. TigDog `moving` 출력은 0.20→1.00초였으나 4종 정확도 개선은 아직 증명되지 않았다.

- [파트 22 — 공식 공개 데이터](22_공개_모션데이터_검증.md): 실제 개 모션 파일 51개, 촬영 그룹 30개, 195/12/13 구간 분리. 출처·이용 조건·해시·시간축 확인. 임의 행동 라벨 없이 사전학습에 사용.
- [파트 23 — LSTM v2](23_LSTM_특징_불확실성_개선.md): 8개 특징, 저확신·좌표 급변 unknown, v1 호환·백업, 공개 모션 사전학습과 합성 행동 분류. 모션 테스트 오차는 단순 기준보다 9.6% 높아 실제 성능 향상은 미확인.
- [파트 24 — RAG v2](24_RAG_기간_의미검색_개선.md): 한국 시간 기간, 보호자 메모·케어 근거, 실제 Gemini 의미 검색·캐시·명시적 폴백. 자체 20질문 Recall@5 25%→100%, Top-1 60%. 독립 실제 사용자 평가가 아님.
- 실제 embedding→공식 MCP→Gemini→인용 통합 검증 성공, 특징 v2가 API에 연결됨. 로컬 의미 검색 활성화. 백엔드 8010, 웹 8020.

추가 계획 6개 중 타임라인·평가 수치·프로필·피드백·전후 비교 인터페이스를 구현했다. 평소 패턴은 계산 및 표본 기준을 구현했지만 실제 장기 기록이 없어 적용 검증은 미완료다.

## 핵심 검증 한계

[파트 25 — 실제 공개 데이터 성능 비교](25_실제데이터_성능비교.md): TigDog 사람 판정과 원본 영상 시각을 확인해 평가했다. 최종 적격 이동 구간 9개에서 v1/v2 재현율 모두 44.4%, unknown 5개였다. 실제 성능 향상은 확인되지 않았다. 비이동·회전·왕복의 독립 정답이 부족해 전체 4종 정확도는 미평가다. 실제 좌표 예측의 고정 모델 비교도 v2 오차가 약 0.98% 더 컸다. 다음 우선순위는 추적 실패와 카메라 이동 영향 개선, 실내 조건의 독립 정답 데이터 확보다.

- LSTM 100%는 합성 테스트 400개 성적이다. 실제 반려견 행동 정확도는 아니다.
- 음성은 에너지 기반 후보다. 공개 비개 소리 15개 중 3개에서 오탐이 확인됐다.
- DAVIS는 JPEG 시퀀스다. 재생용 5fps 시간축과 원본 녹화 시간을 구분한다. 카메라 이동 미보정, 다른 음원과의 결합은 합성 시연이다.
- 가상 음악 완료는 물리 음악 재생이 아니다. 전후 관찰 변화는 음악의 인과 효과가 아니다.
- 실제 브라우저 연속 클릭 시연·영상은 아직 미검증이다. Pi SSH 가상 명령 왕복은 파트 20에서 확인했다. 카메라·마이크·물리 음악 재생은 미검증이다.

## 다음 작업

실제 브라우저 연속 시연·녹화는 아직 검증하지 않았다. 이전 실행 세션에서 Browser 연결 모듈 오류가 있었으며 [파트 17](17_브라우저_연결준비.md)에 기록했다. 새 환경에서 다시 확인해야 한다.

1. 실제 Gemini·MCP·인용은 검증했다. 키는 로컬 `.env`에만 유지하며 발표에서는 실제 제공자와 인용 근거를 표시한다.
2. 화면 캡처와 최종 웹 빌드를 확인하고 실제 브라우저 연결이 가능해지면 연속 시연·영상·복구 절차를 검증한다.
3. Pi 가상 명령 왕복은 검증됐다. 실제 카메라·마이크·음악 재생과 연결 복구를 다음 단계로 검증한다.
4. A2D에서는 탐지 후보의 박스 재현율이 올랐지만 두 InterPet 원본의 분류 coverage는 0%다. 고정 카메라/영상 안정화와 ID 연속성, 4종의 시간별 정답 확보가 다음 기술 작업이다. 이후 실제 라벨·장기 관찰·보호자 의견으로 정확도와 케어 효과를 평가한다.
