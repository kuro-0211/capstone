# PetMind 중간발표 시연 체크포인트

기준일: 2026-10-11. PetMind는 반려견의 감정·질환을 소리나 움직임으로 단정하지 않는다. 외출 중 관찰 신호를 반려견별 기록으로 남기고, 원본·보호자 의견·과거 근거를 함께 보여 보호자가 케어 제안을 검토하게 한다. 급식기와 추가 센서는 현재 범위에서 제외한다.

## 3분 발표 흐름

1. [Genesis 적용 전후 화면](37_Genesis_UI_적용_비교.md)을 15초 동안 비교한다. 기존 다크 화면의 원시 시각·한 줄 수치가 현재 밝은 카드·한국 시간·분리된 핵심 수치로 바뀌었다. 비교 이미지는 디자인 적용 당시 위젯 렌더이고, [현재 브라우저 첫 화면](assets/ui/verified_browser_dashboard_top.png)은 별도로 확인했다.
2. **사용자 음원** 모드로 외출을 시작한다. [검증된 공개 ESC-50 음원](evidence/esc50_presentation_audio_manifest.json)을 출처·저장 동의와 함께 올린다. 5초 분석 창과 원본 재생을 보여준다. 모델 점수는 정확도·확률이 아니며, ‘짖음 후보’ 에너지 신호와 구분한다.
3. 감지된 Dog와 놓친 Dog를 함께 보여준다. 개발 PC의 특정 파일 점수는 `5-203128-A-0.wav` **93.9/100**, `1-100032-A-0.wav` **44.5/100**, 기준 **90/100**이었다. 새 환경에서는 `/health`의 체크포인트 상태와 실제 화면 점수를 먼저 확인한다.
4. 시연 담당자 의견을 저장한 뒤 귀가 요약에서 분석 표본·판단 불가·공개 시연 출처를 확인한다. [근거 질문 화면](assets/ui/verified_browser_duration_question.png)에서는 답의 관찰 번호를 눌러 원본으로 돌아간다. 브라우저 확인의 설명 제공자는 **규칙 기반**, 검색은 **로컬**이었다. 생성형 Gemini 응답의 실시간 시연이라고 소개하지 않는다.
5. [오디오 LSTM 비교 기록](evidence/audio_lstm_three_way.json)을 보여준다. 증강·MIL 후보는 검증 평균 F1이 올랐지만 기존 FSD 평가 F1은 **0.436→0.430**으로 하락해 운영 모델을 교체하지 않았다. 공개 음원 결과는 실제 가정 정확도가 아니다.

위 흐름을 설명하는 [2분 57초 영상과 현장 실행 절차](39_Genesis_브라우저_설명영상.md)가 있다. 영상 파일은 로컬 `artifacts/presentation_20261011/petmind_genesis_browser_walkthrough.mp4`에 있으며 Git에는 없다. 실제 브라우저 캡처를 편집한 설명 영상이고, **연속 클릭 녹화는 아니다**. 영상의 5초 귀가 요약은 놓친 사례 한 건의 별도 화면이다. 현장에서 서로 다른 5초 파일 두 개를 한 외출에 올리면 분석 표본은 10초가 된다.

## 구현·검증 상태

| 항목 | 확인된 결과 | 남은 범위 |
|---|---|---|
| 화면 | Genesis 스타일 적용, 모바일 390px 테스트, 연결 상태·입력 오류·부분 API 장애 안내 | 실제 다양한 기기 사용성 검증 |
| 음원·외출 | 공개 WAV 업로드→원본 구간→시연 의견→귀가/하루 요약→근거 링크 | 실시간 마이크와 실제 보호자 장기 자료 |
| RAG | 반려견별 기록 검색·근거 ID·수치 일치, 이전 외출에 인용된 기록의 원본도 열기, 시연에서는 로컬 검색/규칙 제공자 | 다양한 사용자 질문과 실제 장기 기록에서 독립 평가 |
| 오디오 LSTM | ESC-50/FSD50K 분할 평가, 감지·놓침 공개, 개선 없는 후보 미채택 | 실제 가정 소음과 사람의 시간별 정답으로 독립 평가 |
| 새 환경 | 체크포인트 없는 Git 작업 폴더에서 Python **113 통과·1 건너뜀**, Flutter **15 통과**, 웹 빌드, 음원 4개 다운로드·해시 검증, 영상 재생성 | 새 Python 가상환경에 의존성을 처음부터 설치하는 검증 |
| 현재 개발 폴더 | Python **115 통과**, Flutter **17 통과**, Flutter 정적 분석·웹 빌드 완료 | 연속 클릭 화면 녹화 |

체크포인트·개인 DB·원본 공개 데이터·영상 빌드 결과는 Git에 올리지 않는다. 새 PC에 모델 파일이 없으면 `/health`가 `audio_lstm_checkpoint_present: false`를 보고하고 화면은 모델 미준비를 표시한다. 이 경우에도 공개 WAV→외출 요약→근거 설명의 기록 흐름은 별도 DB에서 검증됐다. [전체 수정 기록](38_자체피드백_안정성_출처_사용성.md)에 재현 범위와 실패 사례를 남겼다.
